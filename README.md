# Family ScreenSync AI

Hackathon prototype: a simulated living-room dashboard where an Alexa+ style agent turns many voices into one family movie pick.

Prototype: https://v0-family-screensync.vercel.app

The UI is the single-file page in public/index.html, served at / by a rewrite in next.config.mjs.

    pnpm install
    pnpm dev
